# Hedemora-Säter Brukshundklubb – Ny hemsida

Modern, responsiv hemsida för Hedemora-Säter Brukshundklubb (brukshundklubb i Skoga utanför Hedemora, grundad 1949).

## Struktur

```
hedemora-sater-bk/
├── index.html              # Startsida
├── css/
│   └── style.css           # All styling
├── js/
│   └── main.js             # Mobilmeny m.m.
├── pages/
│   ├── om-oss.html         # Om klubben
│   ├── traning.html        # Träningstider (tis/ons/tor/lör)
│   ├── kurser.html         # Valpkurs, lydnad, rally, nosework
│   ├── tavling.html        # Officiella & interna tävlingar, KM
│   ├── medlemskap.html     # Bli medlem, avgifter
│   ├── kontakt.html        # Adress, e-post, formulär
│   ├── nyheter.html        # Nyhetslista
│   └── lankar.html         # Nyttiga länkar
└── README.md
```

## Så öppnar du

Öppna `index.html` i en webbläsare (dubbelklicka eller dra in i Chrome/Firefox/Safari).  
Alla länkar fungerar lokalt – inga servrar behövs.

## Design

- Grön/guld färgpalett (brukshund / natur)
- Responsiv (mobilmeny under 900px)
- Modern typografi och kortbaserad layout
- Sticky header, tydlig CTA ”Bli medlem”
